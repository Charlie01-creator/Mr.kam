# Kamulegeya Mathematics — website source

Static site generated by `build.py` (standard library only; built and tested on Python 3.12, Vercel's current default). **Edit source files, never `dist/`** — `dist/` is regenerated on every build (Vercel runs `python3 build.py` itself).

## Structure
| Path | Purpose |
|---|---|
| `build.py` | Generator: config, publications, resources, all page templates, SEO/JSON-LD, robots/sitemap/llms.txt |
| `assets/site.css` | Design system. Tokens (colours, fonts, widths) are in `:root` at the top |
| `assets/site.js` | Mobile menu + enquiry forms (no dependencies) |
| `assets/fonts/` | Self-hosted Lora + Source Sans 3 (subset, WOFF) |
| `assets/img/` | **Real photographs go here** (see below) |
| `assets/resources/` | PDFs for the resource library (see below) |
| `audit.py`, `check_deploy.py` | SEO/structure audit and pre-deploy crawl |
| `browser_test.py` | Optional real-browser tests (needs Playwright) |
| `tools/make_og.py` | Regenerates `assets/og.png` (needs Pillow) |
| `vercel.json` | Build config, security headers (CSP, Permissions-Policy, etc.), caching |

## Adding the real images (no code changes needed)
Drop files in `assets/img/`, rebuild. They replace the labelled slots automatically, with alt text generated.
- `portrait.jpg` (or `.webp` / `.png`) — portrait, ideally 4:5, about 1200×1500 px, under ~250 KB
- `cover-essentials-of-applied-mathematics.jpg` (or `.webp` / `.png`) — front cover, 2:3, about 800×1200 px
- `sample-essentials-of-applied-mathematics-1.jpg`, `-2.jpg`, … — sample pages, **only if the author permits**
For a new book, use `cover-<slug>.ext` where `<slug>` is the book's `slug` in `BOOKS`.
Optimise images before adding (WebP or well-compressed JPEG). If Pillow is installed, width/height attributes are added automatically.

## Adding verified information
- **Contact:** fill `CFG` in `build.py` (phone, WhatsApp digits with country code, email). They appear on the Contact page and enable the WhatsApp/email send buttons on every form. Leave blank until verified.
- **New book:** append to `BOOKS` (`slug`, `title`, `edition`, `desc`, `topics`; optional `publisher`, `isbn`, `pages`, `audience`, `contents`). Catalogue, detail page, order form, sitemap, JSON-LD and "related publications" update automatically.
- **Resources:** put the PDF in `assets/resources/` and add `{"title","category","kind","file","desc"}` to `RESOURCES`. The empty state disappears.
- **Educational philosophy:** replace the reserved block in the About page with his own words when supplied.

## Build, test, deploy
```
cd site
python3 build.py                       # or: python3 build.py https://your-domain  (enables canonicals + sitemap.xml)
python3 audit.py && python3 check_deploy.py
python3 browser_test.py                # optional: pip install playwright && playwright install chromium
```
**Vercel:** project root directory = `site`; build command `python3 build.py`; output directory `dist` (already in `vercel.json`).
Set environment variable `SITE_URL=https://your-real-domain` in Vercel (Project → Settings → Environment Variables) so canonical URLs, Open Graph URLs and `sitemap.xml` are generated. Do not guess a domain.
